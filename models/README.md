# Trained Models

This directory stores trained model artifacts generated by `src/train.py`.

## Files (generated after training)

- `best_model.joblib` — The best-performing model serialized with joblib
- `scaler.joblib` — The fitted StandardScaler for feature preprocessing
- `label_encoder.joblib` — The fitted LabelEncoder for target variable

## Usage

These files are generated automatically during training:

```bash
python src/train.py
```

They are loaded during prediction by `src/predict.py` and `app.py`.

> **Note:** Model files (`.joblib`) are excluded from version control via `.gitignore`
> because they are binary artifacts that can be regenerated by running the training script.
